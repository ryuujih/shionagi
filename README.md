# 汐凪 / SHIONAGI

2089年の日本の漁師町「汐凪」を舞台にした、サイバーパンクなオープンワールドTPS。海と山に囲まれた街を徒歩や乗り物で探索し、人々との会話やミッションを通じて島々の物語を紡ぐ。

ブラウザで遊べる開発中のプロトタイプです。瀬戸内海の島々や日本の漁港の雰囲気をもとにした架空の街を、Three.jsによる3D空間で表現しています。

## 遊べる内容

- 漁港、商店街、東浜夜市、山灯の集落、展望台、青汐島、灯台の探索
- 主人公レンを操作する三人称視点と、人物・ロボット・交通車両が動く街
- ホバーバイク、電動軽トラック、水上タクシー、スカイポッドの運転
- 会話・調査・コア運搬・ドローン戦を含む全6ミッション「帰港灯のない夜」
- EMP射撃、ロックオン、装填、回避、チェックポイントからの再挑戦
- 終盤の選択による結末の分岐、昼夜の切り替え、地図からの移動

## 起動方法

Node.js 24系とnpmを使用してください（Node.js 24.16.0で動作確認）。WebGL 2に対応したブラウザが必要です。外部APIキーやバックエンドサーバーの設定は不要です。

```sh
git clone https://github.com/ryuujih/shionagi.git
cd shionagi
npm ci
npm run dev -- --host 127.0.0.1
```

ターミナルに表示されるURLを開きます。通常は <http://127.0.0.1:5173/> です。

- **物語をプレイ**：シナリオを開始。保存がある場合はチェックポイントから再開します。
- **自由探索をはじめる**：街の散策と乗り物の運転を楽しめます。

## 操作方法

### 徒歩・TPS

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D |
| 視点操作 | マウス、または画面をドラッグ |
| 前後移動・視点旋回 | ↑ / ↓・← / → |
| 早歩き | Shift |
| 回避 | Space |
| 会話・調査・乗降 | E |
| EMP射撃（物語モード） | 左クリック / J |
| ロックオン・解除 | Q |
| 装填 | R |
| 任務ログ | L |
| 地図 | M |
| 車庫 | V |
| 街の話を読む（自由探索） | F |
| 一時停止 | Esc |

### 乗り物

| 操作 | キー |
| --- | --- |
| 加速・減速／後退 | W / S |
| ハンドル | A / D |
| ブレーキ | Space |
| 低速巡航の切り替え | C |
| 降車 | E |
| スカイポッドの上昇・下降 | R / Q |

降車する際は停止してください。水上タクシーは岸や桟橋の近く、スカイポッドは地上近くで降りられます。車庫で別の乗り物を選ぶと、その乗り物の場所へ移動します。

## ミッションと保存

任務ログで現在の目的を確認できます。各地へ自分で向かうほか、「目的地へ移動して再開」も利用できます。

ミッション完了時に、進行状況と選択した結末をブラウザの `localStorage` に自動保存します。途中の戦闘状態や自由探索中の位置は保存されません。散策地点の記録は今回のプレイ中のみ残ります。

保存はブラウザと接続先URLごとに独立しています。別のブラウザ・ポート・ホスト名では引き継がれません。ブラウザのサイトデータを削除すると保存も消えます。

## ビルド・テスト

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

`npm run build` はTypeScriptのチェックと本番ビルドを行い、`dist/` に出力します。`npm run preview` のURLはターミナルで確認してください。

自動テストでは、地形・衝突・車両の加減速・橋の通行・降車制限・ミッションの進行・保存データの検証・射線判定・歩行の停止・フレームレート差を確認しています。

開発時にはデスクトップブラウザで乗降、巡航、一時停止、戦闘、全ミッションの完了と保存後の再開も確認しています。タッチ操作用のUIはありますが、タッチ端末での実機検証は未実施です。

## 技術構成

React 19 / TypeScript / Three.js / Vite 7 / Tailwind CSS 4

| ファイル | 役割 |
| --- | --- |
| `src/App.tsx` | タイトル、地図、車庫、操作UI |
| `src/world.ts` | 3Dシーン、カメラ、入力、ゲームループ |
| `src/geography.ts` | 地形、移動可能範囲、地点情報 |
| `src/simulation.ts` | 移動、車両挙動、衝突判定 |
| `src/city-life.ts` | 人物・ロボット・乗り物・街の演出 |
| `src/expansion.ts` | 追加地区と景観 |
| `src/campaign.ts` | ミッション定義と進行管理 |
| `src/story-world.ts` | 主人公、敵、戦闘、セーブ |
| `src/components/mission-ui.tsx` | 任務ログ、会話、戦闘HUD |
| `src/world.test.ts` | 自動テスト |

## 現在の制限

- モデルとアニメーションはコードで構築した簡易表現です。
- 交通・衝突・戦闘はプロトタイプ向けの簡易シミュレーションです。
- シングルプレイ専用で、オンライン同期やクラウドセーブはありません。
- 描画負荷と操作性は今後も調整予定です。
